# Парк Арктики · 360°

Исходники плагина для Figma Design. Десять иллюстративных объёмных моделей самолётов из материала «Небо над Арктикой».

## Что готово

- Каталог десяти моделей; у каждой своя геометрия крыла, хвоста, двигателей и корпуса.
- Поворот на 360° мышью, касанием, клавиатурой и ползунком, настройка наклона и масштаба.
- Четыре готовых ракурса: перспектива, сбоку, спереди, сверху.
- PNG-экспорт выбранного ракурса 1600 × 1000 с прозрачным или тёмно-синим фоном.
- Вставка изображения на текущую страницу Figma, сохранение параметров ракурса и повторный запуск.
- Валидация модели, размеров, параметров и PNG; сообщения об ошибке и успехе.

Вращение происходит в интерфейсе плагина. На холст Design добавляется изображение выбранного ракурса. Это не нативный редактируемый 3D-объект Figma.

## Состав

`ui.html` — самодостаточный интерфейс. Геометрия и программный 3D-рендер встроены внутрь; внешние библиотеки, сеть и ключи API не требуются. Управление использует элементы `fig-*`, с автономным резервным оформлением для локального предпросмотра.

`code.ts` — код Figma Plugin API. Запускает окно, принимает PNG, создаёт изображение рядом с центром viewport, выбирает результат и сохраняет параметры для повторного запуска.

Общий движок совпадает с `site/fleet-geometry.js` в этом репозитории. Рендер использует настоящий буфер глубины и освещение треугольной геометрии, поэтому не зависит от WebGL.

## Проверка

Проверено программно: все десять моделей рисуются в пяти углах, 0° и 360° совпадают; ракурсы отличаются; формируется прозрачный PNG 1600 × 1000. Контракт с кодом Figma проверен на mock Plugin API: вставка, выделение результата, восстановление параметров, отказ от четырёх видов некорректных входных данных.

В разрешённом браузерном предпросмотре проверен интерфейс шириной 520 px: выбор самолёта, переключение ракурсов, поле поворота и размещение элементов.

Native сборка полного плагина в Figma завершилась успешно. Фактическая вставка изображения через окно плагина в реальный canvas Figma не выполнялась и не заявляется как проверенная.
