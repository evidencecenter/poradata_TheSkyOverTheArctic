# Небо над Арктикой

Интерактивный дата-лендинг «ПОРА считать» об авиасообщении в Арктической зоне России: структура сети, крюки между соседними аэропортами, парк, сезонность, цены и субсидии. Страница — один файл `index.html` без внешних зависимостей, кроме шрифтов Google Fonts (Forum для заголовков, Inter для текста, IBM Plex Mono для подписей осей) и фотографии первого экрана из папки `img/`. Иконки глав — миниатюры данных каждой главы, их рисует сам скрипт страницы.

## Структура

```
index.html                 готовая страница (данные встроены)
site/index.template.html   шаблон страницы (HTML и CSS)
site/app.js                скрипт страницы: карты, графики, калькулятор поездки, сноски
site/data.js               данные для страницы (window.DATA)
site/artifact.html         версия без каркаса документа (для публикации как артефакт claude.ai)
img/hero.jpg, hero-m.jpg   фотография первого экрана (северное сияние над плато Путорана)
data/raw/                  исходные файлы: расписание и цены Aviastats, реестр аэродромов, табло Яндекса
data/processed/            очищенные данные и рассчитанные показатели
scripts/00_basemap.py      карта-подложка: Natural Earth, коническая равновеликая проекция
scripts/01_clean.py        очистка расписания, дедупликация рейсов, заполнение пропусков, восстановление местного времени и UTC
scripts/02_metrics.py      структура сети, местные сети, сезонность, парк, связность, индекс крюка
scripts/03_prices.py       цены: цена километра, глубина бронирования, сезонность цен
scripts/04_yandex_check.py сверка расписания с табло Яндекс Расписаний
scripts/04b_extra.py       время в пути по расписанию, дни без вылетов, чувствительность порога, цена при равном расстоянии,
                           конкуренция, цена в рабочих днях, сутки рейсов для анимации, аэродромы без данных (data/processed/extra.json)
scripts/05_build_site_data.py  сборка site/data.js
scripts/06_build_html.py   сборка index.html и site/artifact.html
```

## Как пересобрать

```
pip install -r requirements.txt
python scripts/01_clean.py && python scripts/02_metrics.py && python scripts/03_prices.py \
  && python scripts/04_yandex_check.py && python scripts/04b_extra.py && python scripts/05_build_site_data.py \
  && python scripts/06_build_html.py
```

Шаг `00_basemap.py` требует файлов Natural Earth (`ne_10m_admin_0_countries_rus`, `ne_10m_admin_1_states_provinces`, `ne_50m_admin_0_countries`), результат уже лежит в `data/processed/basemap.json`.

## Данные

Источник данных — Aviastats, сервис для анализа авиационной отрасли России; при публикации результатов указывайте его как источник.

- Расписание Aviastats: 109 393 записи о рейсах через 36 аэропортов АЗРФ, 15.01.2025 — 31.12.2026; 106 616 физических рейсов после объединения записей одного рейса под номерами разных авиакомпаний. Период расчётов — октябрь 2025 — сентябрь 2026 года (56 277 рейсов): местные рейсы Якутии появляются в выгрузке только с октября 2025 года, поэтому 2025 календарный год занижает местную сеть.
- Время в выгрузке. Местное время всех аэропортов записано в ней как московское: столбцы UTC = местное время − 3 часа, а «местное время» получено из них прибавлением пояса аэропорта (поэтому рейс Норильск → Москва по выгрузке длится 30 минут). Признаки: дата вылета во всех записях совпадает с датой «UTC + 3 часа»; на табло Яндекса в Мурманске, Архангельске и Нарьян-Маре время рейсов в другие пояса совпадает с выгрузкой в обе стороны; у рейсов туда-обратно разница длительностей равна двойной разнице поясов, а разворот самолёта в аэропорту назначения занимает обычные 40–100 минут. Шаг 1 восстанавливает местное время (UTC выгрузки + 3 часа) и UTC (местное − пояс аэропорта) для 62 037 рейсов; пояса Депутатского, Усть-Куйги, Саккырыра и Барнаула в выгрузке тоже неверные и исправлены. После пересчёта неправдоподобное время полёта осталось у 37 рейсов, их прилёт взят по медиане маршрута. Пояс каждого аэропорта записан в `data/processed/airports.csv` (`tz_utc_min`).
- Минимальные цены Aviastats: 43 240 наблюдений по 345 маршрутам, вылеты 20.11.2025 — 31.12.2026, цена за 30, 14 и 3 дня до вылета.
- Государственный реестр аэродромов и вертодромов гражданской авиации (Росавиация, на 27.04.2026) с разметкой АЗРФ и классами аэродромов.
- Табло Яндекс Расписаний по Мурманску, Архангельску и Нарьян-Мару за отдельные даты 2026 года (время в файле — UTC): 482 из 489 рейсов табло найдены в выгрузке Aviastats.
- Пассажиропоток аэропортов Мурманска и Апатитов за январь — июнь 2026 года (Минтранс Мурманской области, ABN24) — для сверки мест с пассажирами; средняя начисленная зарплата по регионам за август 2026 года (Росстат, по публикации Т—Ж) — для цены в рабочих днях.
- Субсидируемые направления: расчёты ПОРА по перечню Росавиации на 2026 год (цифры из презентации «Авиатранспортная доступность в Арктике», часть 1).

## Ключевые правила расчёта

- Физический рейс = время вылета UTC + пара аэропортов; места — верхняя граница вместимости судна.
- Узловые аэропорты: вне АЗРФ, топ-5 по местам, рейсам или направлениям. Магистральные (в презентации ПОРА — корневые) аэропорты АЗРФ: с прямыми рейсами в узловые, включая другие аэропорты того же города. Местные: остальные аэропорты АЗРФ. Центры местных сетей вне АЗРФ: Якутск, Красноярск (с Черемшанкой), Магадан, Полярный.
- «Внутри Арктики и местных сетей»: рейсы между аэропортами АЗРФ и рейсы местных аэропортов к центрам их сетей.
- Регулярная связь корневых аэропортов: в обе стороны не реже раза в неделю в 47 недель года есть прямой рейс или стыковка с одной пересадкой от 1 до 12 часов.
- Время в пути: для каждого вылета из аэропорта АЗРФ — самый ранний прилёт во все аэропорты АЗРФ по расписанию (до двух пересадок, не меньше часа на пересадку в том же аэропорту и четырёх часов между аэропортами одного города, прибытие в пределах трёх суток; рейс с промежуточной посадкой под одним номером — без пересадки). Для пары и дня берётся самый быстрый вариант, затем медиана по дням. Прямой рейс оценивается по расписанию турбовинтовых самолётов: 36,7 минуты плюс 0,128 минуты на километр (52 маршрута).
- Крюк: кратчайший путь по направленному графу рейсов (ортодромия), два варианта графа — круглогодичные направления (рейсы не меньше чем в 40 из 52 недель периода) и все направления периода.
- Цена километра: медиана цены за 30 дней до вылета по датам с 01.10.2025 по 30.09.2026, делённая на ортодромию; маршруты с более чем 10 вылетами за год. Малые борта — маршруты через аэродромы классов Г, Д, Е. Сравнение при равном расстоянии — медианы в диапазонах дальности, сопоставление маршрутов одной длины (±20 %) и регрессия логарифма цены на логарифм расстояния.
- Цена в рабочих днях: цена, делённая на среднюю начисленную зарплату за август 2026 года в регионе арктического аэропорта маршрута и умноженная на 21 рабочий день.
