# Небо над Арктикой

Интерактивный дата-лендинг «ПОРА считать» об авиасообщении в Арктической зоне России: структура сети, крюки между соседними аэропортами, парк, сезонность, цены и субсидии. Текущая редакция — v4.

## Готовый сайт

`index.html` в корне — готовая автономная страница. В неё встроены данные, карты, стили, скрипты, изображения, шрифты, 3D-галерея и эффекты прокрутки. Для публикации готовой страницы установка зависимостей не требуется.

Для локального просмотра откройте `index.html` в браузере.

## Загрузка на GitHub и публикация через GitHub Pages

1. Распакуйте ZIP.
2. Откройте нужный репозиторий GitHub и выберите **Add file → Upload files**.
3. Загрузите содержимое распакованной папки. **Файл `index.html` должен лежать непосредственно в корне репозитория**, рядом с `README.md`, а не внутри дополнительной папки.
4. Сохраните файлы кнопкой **Commit changes** в ветку `main`.
5. Откройте **Settings → Pages**.
6. В **Build and deployment → Source** выберите **Deploy from a branch**.
7. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
8. После завершения публикации адрес сайта появится в этом же разделе Pages.

Если основная ветка вашего репозитория называется иначе, выберите её вместо `main`.

В архив включён пустой файл `.nojekyll` для статической публикации. Если файловый менеджер скрывает имена, начинающиеся с точки, включите показ скрытых файлов перед загрузкой.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Пересборка после редактирования

Из корня проекта выполните в Python 3:

```bash
python scripts/build_editorial.py
```

Скрипт использует стандартную библиотеку Python. Он обновит корневой `index.html` и дополнительно создаст `dist/index.html` и `site/artifact.html`. Эти два дополнительных файла для публикации из корня GitHub Pages не нужны.

Проверка после пересборки:

```bash
python scripts/build_editorial.py --check
```

После правок загрузите в GitHub обновлённые исходники и новый корневой `index.html`.

Сборщик проверяет контрольные суммы `site/app.js` и `site/data.js`, чтобы редактирование дизайна случайно не меняло расчёты и данные. Публикация использует готовые данные; повторный запуск аналитического конвейера не требуется.

Лицензия на включённые шрифты находится в `site/assets/fonts/LICENSE.txt`.

## Расчёты

Данные для страницы готовит конвейер на Python:

```
scripts/01_clean.py        очистка расписания, дедупликация рейсов, заполнение пропусков, восстановление местного времени и UTC
scripts/02_metrics.py      структура сети, местные сети, сезонность, парк, связность, индекс крюка
scripts/03_prices.py       цены: цена километра, глубина бронирования, сезонность цен
scripts/04_yandex_check.py сверка расписания с табло Яндекс Расписаний
scripts/04b_extra.py       время в пути по расписанию, дни без вылетов, чувствительность порога, цена при равном расстоянии,
                           конкуренция, цена в рабочих днях, сутки рейсов для анимации, аэродромы без данных (data/processed/extra.json)
scripts/05_build_site_data.py  сборка site/data.js
data/processed/            очищенные данные и рассчитанные показатели
```

Исходных выгрузок и подложки карты в репозитории нет. Скрипты ждут выгрузки в папке `data/raw/` (`flights_ru_arctic.xlsx`, `min_prices_direct_ru_arctic.xlsx`, `reestr_aerodromov_azrf.xlsx`, `yandex_flights.csv`), а подложку карты шаг 5 берёт из `data/processed/basemap.json`.

Пересчёт:

```bash
pip install pandas numpy openpyxl
python scripts/01_clean.py && python scripts/02_metrics.py && python scripts/03_prices.py \
  && python scripts/04_yandex_check.py && python scripts/04b_extra.py && python scripts/05_build_site_data.py
```

Шаг 5 перезаписывает `site/data.js`, и сборщик страницы откажется работать: он сверяет контрольные суммы `site/data.js` и `site/app.js`. После пересчёта или правки `site/app.js` впишите новые суммы SHA-256 в `IMMUTABLE_SOURCES` в `scripts/build_editorial.py` (их выводит `sha256sum site/data.js site/app.js`) и запустите `python scripts/build_editorial.py`.

## Данные

Источник данных — Aviastats, сервис для анализа авиационной отрасли России; при публикации результатов указывайте его как источник.

- Расписание Aviastats: 109 393 записи о рейсах через 36 аэропортов АЗРФ, 15.01.2025 — 31.12.2026; 106 616 физических рейсов после объединения записей одного рейса под номерами разных авиакомпаний. Период расчётов — октябрь 2025 — сентябрь 2026 года (56 277 рейсов): местные рейсы Якутии появляются в выгрузке только с октября 2025 года, поэтому 2025 календарный год занижает местную сеть.
- Время в выгрузке. В столбцах UTC на самом деле местное время по расписанию, а столбцы «местное время» получены из них прибавлением пояса аэропорта (поэтому рейс Норильск → Москва по выгрузке длится 30 минут). Признаки: на табло Яндекса в Мурманске, Архангельске и Нарьян-Маре местное время рейсов совпадает со столбцом UTC; у рейсов туда-обратно разница длительностей равна двойной разнице поясов, а разворот самолёта в аэропорту назначения занимает обычные 40–100 минут; вылеты из Москвы и Петербурга в столбце UTC затихают в 4–5 часов — ночное затишье по местному времени. Шаг 1 берёт местное время из столбца UTC и считает настоящее UTC по поясу аэропорта (длительность меняется у 62 037 рейсов), дату вылета пересчитывает по местному времени; пояса Депутатского, Усть-Куйги, Саккырыра и Барнаула в выгрузке тоже неверные и исправлены. У 37 записей время полёта и после этого невозможное. Это не физические рейсы: выгрузка показывает то, на что продают билеты, и стыковку под одним номером записывает как один рейс (например, Санкт-Петербург — Салехард на 16 часов). Шаг 1 такие записи исключает. Пояс каждого аэропорта записан в `data/processed/airports.csv` (`tz_utc_min`).
- Выгрузку сделали 7 сентября 2026 года: рейсы позже этой даты — расписание на тот день. Поэтому регулярную связь аэропортов считаем за сентябрь 2025 — август 2026 года.
- Рейс с промежуточной посадкой записан как отдельные рейсы до каждой точки (около 1 % записей), их кресла мы считаем дважды.
- Минимальные цены Aviastats: 43 240 наблюдений по 345 маршрутам, вылеты 20.11.2025 — 31.12.2026, цена за 30, 14 и 3 дня до вылета.
- Государственный реестр аэродромов и вертодромов гражданской авиации (Росавиация, на 27.04.2026) с разметкой АЗРФ и классами аэродромов.
- Табло Яндекс Расписаний по Мурманску, Архангельску и Нарьян-Мару за отдельные даты 2026 года (время в файле — UTC): 482 из 489 рейсов табло найдены в выгрузке Aviastats.
- Пассажиропоток аэропортов Мурманска и Апатитов за январь — июнь 2026 года (Минтранс Мурманской области, ABN24) — для сверки кресел с пассажирами; средняя начисленная зарплата по регионам за август 2026 года (Росстат, по публикации Т—Ж) — для цены в рабочих днях.
- Субсидируемые направления: расчёты ПОРА по перечню Росавиации на 2026 год (цифры из презентации «Авиатранспортная доступность в Арктике», часть 1).

## Ключевые правила расчёта

- Физический рейс = время вылета UTC + пара аэропортов; кресла считаем по максимальной вместимости самолёта. Пассажиропоток оцениваем по креслам (провозной ёмкости), а не по проданным билетам.
- Узловые аэропорты: вне АЗРФ, топ-5 по креслам, рейсам или направлениям. Магистральные (в презентации ПОРА — корневые) аэропорты АЗРФ: с прямыми рейсами в узловые, включая другие аэропорты того же города. Местные: остальные аэропорты АЗРФ. Центры местных сетей вне АЗРФ: Якутск, Красноярск (с Черемшанкой), Магадан, Полярный.
- «Внутри Арктики и местных сетей»: рейсы между аэропортами АЗРФ и рейсы местных аэропортов к центрам их сетей.
- Регулярная связь магистральных аэропортов: в обе стороны не реже раза в неделю в течение 47 из 52 недель (около 90 %) есть прямой рейс или стыковка с одной пересадкой от 1 до 12 часов; окно — сентябрь 2025 — август 2026 года.
- Время в пути: для каждого вылета из аэропорта АЗРФ — самый ранний прилёт во все аэропорты АЗРФ по расписанию (до двух пересадок, не меньше часа на пересадку в том же аэропорту и четырёх часов между аэропортами одного города, прибытие в пределах трёх суток; рейс с промежуточной посадкой под одним номером — без пересадки). Для пары и дня берётся самый быстрый вариант, затем медиана по дням. Прямой рейс оценивается по расписанию турбовинтовых самолётов: 36,7 минуты плюс 0,128 минуты на километр (52 маршрута).
- Крюк: кратчайший путь по направленному графу рейсов (ортодромия), два варианта графа — круглогодичные направления (рейсы не меньше чем в 40 из 52 недель периода) и все направления периода.
- Цена километра: медиана цены за 30 дней до вылета по датам с 20.11.2025 (раньше цен нет) по 30.09.2026, делённая на ортодромию; только маршруты, которые покрываются рейсами расписания (больше 10 вылетов за год). Малые борта — маршруты через аэродромы классов Г, Д, Е. Сравнение при равном расстоянии — медианы в диапазонах дальности, сопоставление маршрутов одной длины (±20 %) и регрессия логарифма цены на логарифм расстояния.
- Цена в рабочих днях: цена, делённая на среднюю начисленную зарплату за август 2026 года в регионе арктического аэропорта маршрута и умноженная на 21 рабочий день.
