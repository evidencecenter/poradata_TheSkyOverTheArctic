# Небо над Арктикой

Интерактивный дата-лендинг «ПОРА считать» об авиасообщении в Арктической зоне России: структура сети, крюки между соседними аэропортами, парк, сезонность, цены и субсидии. Страница — один файл `index.html` без внешних зависимостей, кроме шрифтов Google Fonts.

## Структура

```
index.html                 готовая страница (данные встроены)
site/index.template.html   шаблон страницы (HTML, CSS, JS)
site/data.js               данные для страницы (window.DATA)
site/artifact.html         версия без каркаса документа (для публикации как артефакт claude.ai)
data/raw/                  исходные файлы: расписание и цены Aviastats, реестр аэродромов, табло Яндекса
data/processed/            очищенные данные и рассчитанные показатели
scripts/00_basemap.py      карта-подложка: Natural Earth, коническая равновеликая проекция
scripts/01_clean.py        очистка расписания, дедупликация рейсов, заполнение пропусков
scripts/02_metrics.py      структура сети, кусты, сезонность, парк, связность, индекс крюка
scripts/03_prices.py       цены: цена километра, глубина бронирования, сезонность цен
scripts/04_yandex_check.py сверка расписания с табло Яндекс Расписаний
scripts/05_build_site_data.py  сборка site/data.js
scripts/06_build_html.py   сборка index.html и site/artifact.html
```

## Как пересобрать

```
pip install -r requirements.txt
python scripts/01_clean.py && python scripts/02_metrics.py && python scripts/03_prices.py \
  && python scripts/04_yandex_check.py && python scripts/05_build_site_data.py && python scripts/06_build_html.py
```

Шаг `00_basemap.py` требует файлов Natural Earth (`ne_10m_admin_0_countries_rus`, `ne_10m_admin_1_states_provinces`, `ne_50m_admin_0_countries`), результат уже лежит в `data/processed/basemap.json`.

## Данные

- Расписание Aviastats: 109 393 записи о рейсах через 36 аэропортов АЗРФ, 15.01.2025 — 31.12.2026. В расчётах используются выполненные рейсы 2025 года (53 227 физических рейсов после объединения записей одного рейса под номерами разных авиакомпаний).
- Минимальные цены Aviastats: 43 240 наблюдений по 345 маршрутам, вылеты 20.11.2025 — 31.12.2026, цена за 30, 14 и 3 дня до вылета.
- Государственный реестр аэродромов и вертодромов гражданской авиации (Росавиация, на 27.04.2026) с разметкой АЗРФ и классами аэродромов.
- Табло Яндекс Расписаний по Мурманску, Архангельску и Нарьян-Мару за отдельные даты 2026 года: 482 из 489 рейсов табло найдены в выгрузке Aviastats.
- Субсидируемые направления: расчёты ПОРА по перечню Росавиации на 2026 год (цифры из презентации «Авиатранспортная доступность в Арктике», часть 1).

## Ключевые правила расчёта

- Физический рейс = время вылета UTC + пара аэропортов; места — верхняя граница вместимости судна.
- Узловые аэропорты: вне АЗРФ, топ-5 по местам, рейсам или направлениям (без корней кустов). Корневые аэропорты АЗРФ: с прямыми рейсами в узловые. Местные: остальные аэропорты АЗРФ. Корни вне АЗРФ: Якутск, Красноярск (с Черемшанкой), Магадан, Череповец, Полярный.
- «Внутри Арктики и кустов»: рейсы между аэропортами АЗРФ и рейсы местных аэропортов к их корням.
- Регулярная связь корневых аэропортов: в обе стороны не реже раза в неделю в 47 недель года есть прямой рейс или стыковка с одной пересадкой от 1 до 12 часов.
- Крюк: кратчайший путь по направленному графу рейсов (ортодромия), два варианта графа — круглогодичные направления (рейсы не меньше чем в 40 из 51 недели 2025 года) и все направления 2025 года.
- Цена километра: медиана цены за 30 дней до вылета по датам с 01.10.2025 по 30.09.2026, делённая на ортодромию; маршруты с более чем 10 вылетами за год. Малые борта — маршруты через аэродромы классов Г, Д, Е.
